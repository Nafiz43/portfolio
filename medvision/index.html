Overview

Hospitals keep years of imaging studies, DICOM headers and radiology reports, yet answering a simple clinical question about them still means opening studies one by one or filing a ticket with IT. MedVision lets clinicians ask that question in plain English, show it an image, or both, and get back an answer they can check: counts and charts, matching studies with their reports, and visually similar cases, each shown with the evidence behind it.

Questions clinicians want to ask

PATIENT CARE

  • Was this lung nodule there 1, 3 or 5 years ago? Did it grow?
  • How many central lines has this patient had, left side and right side?
  • Was this liver lesion treated before? With what therapy?

TEACHING

  • This patient has an aneurysm. Show me other patients with one like it.
  • Find past cases that look like this one.

QUALITY

  • What radiation dose does each scanner deliver for the same study?
  • How many dialysis access interventions this year, and how many repeated within 90 days?

Why current tools fall short

  1. The search box decides what you can ask. The question has to be rewritten to fit fixed fields and search syntax.
  2. Only some details can be combined. Findings plus a few acquisition fields, not any DICOM header with any report finding.
  3. Analytics are limited. Counts and trends beyond the built-in reports need an analyst.
  4. You cannot search with an image. There is no way to show the archive a picture and ask for cases like it.

How it works

PREPARED ONCE, FROM THE ARCHIVE

  • DICOM headers become a table of study and acquisition details.
  • Radiology reports are linked to each study by accession number.
  • Every image frame gets a numeric fingerprint for image search.

ANSWERING A QUESTION

  • A local language model turns the question into a read-only database query.
  • The database runs it. On an error, the assistant reads it and fixes the query.
  • The answer and chart are built from the returned rows.
